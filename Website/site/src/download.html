Why Windows warns you

Windows trusts an installer more when it is code-signed: stamped with a certificate that names its publisher. Veyra doesn't have that certificate yet, so Windows and your browser see Veyra Setup as coming from an unknown publisher and ask you to confirm before running it.

That warning is about the missing signature, not about anything found in the file. Signing will come later in development.

Until then, you can check that your copy is exactly the one we published: compare its SHA-256 with the one on this page. Here's how.

Only download Veyra Setup from this website.

Step by step

How to install Veyra

A few minutes, plus the game's download. You don't need administrator rights: Veyra installs for your Windows user only.

  1. Download Veyra Setup

    Select Download above. Because the file is new and unsigned, your browser may say it isn't commonly downloaded.

    • Chrome: open the downloads list and choose Keep.
    • Edge: hover over the download, choose ⋯, then Keep. If Edge asks again, choose Show more, then Keep anyway.
    • Firefox: if it warns, open the downloads list and choose Allow download.

  2. Check it's genuine (recommended)

    Open PowerShell (search for it in the Start menu) and run this. It prints your file's SHA-256:

    Get-FileHash "$env:USERPROFILE\Downloads\VeyraSetup.exe" -Algorithm SHA256

    The Hash it shows must match the SHA-256 on this page, letter for letter (PowerShell prints it in capitals; that's fine). If it doesn't match, delete the file and don't run it.

  4. Install the launcher

    Setup installs the Veyra launcher to %LOCALAPPDATA%\Programs\Veyra, adds it to the Start menu and, if you like, the desktop. Running Setup again later upgrades it in place.

    On Windows 10, Setup may say the launcher needs Microsoft's WebView2 Runtime and offer its download page. Install it; Windows 11 already has it.

  5. Install the game, sign in, play

    When Setup finishes, the launcher opens on its Install screen. Choose where the game goes (or keep the suggested folder) and select Install. It downloads the game and checks every piece of it.

    Then sign in with the email and password of your Veyra account, or create one there. Select Play.

After you install

Updates, repairs and uninstalling

Updates are automatic

Each time it opens, the launcher checks for a new version of itself and of the game, and installs it before you sign in. You only ever download what changed.

Repair

If the game won't start or seems damaged, select Repair beside the build number on the launcher's sign-in screen. It checks every file and replaces anything that's wrong.

Uninstall

Open Windows Settings → Apps → Installed apps, find Veyra and choose Uninstall. It asks whether to remove the game too.
