Installing

Windows says “Windows protected your PC”

That's Microsoft Defender SmartScreen. It appears because Veyra Setup isn't code-signed yet, so Windows can't name its publisher. Select More info, check the app is the Veyra Setup you downloaded, then select Run anyway.

For peace of mind, first check the file's SHA-256 against the one on the download page.

My browser says the file isn't commonly downloaded

Browsers warn about new files that few people have downloaded yet. Keep it from the downloads list: Keep in Chrome; ⋯ → Keep in Edge, then Show more → Keep anyway if asked; Allow download in Firefox.

There's no “Run anyway” button

Two things can stop unsigned apps outright:

  • Smart App Control (on some Windows 11 PCs) blocks apps without a trusted signature and offers no way past. You can see whether it's on in Windows Security → App & browser control → Smart App Control settings. Turning it off is your decision to make; Veyra will install normally once it's signed.
  • A PC managed by a school or workplace may block unknown apps by policy. Ask whoever manages it.
My antivirus removed or quarantined Veyra Setup

Antivirus tools are more suspicious of new, unsigned installers. If your copy's SHA-256 matches the one on the download page, it is the file we published: you can restore it from quarantine or allow it. If it doesn't match, delete it and download again from this website.

Setup says the launcher needs WebView2

The launcher's window is drawn with Microsoft's WebView2 Runtime. Windows 11 includes it. On Windows 10, Setup offers to open Microsoft's download page: install the runtime, then open Veyra from the Start menu.

Do I need administrator rights?

No. Setup installs the launcher for your Windows user only, in %LOCALAPPDATA%\Programs\Veyra, with no administrator prompt.

Where does the game go, and can I choose?

The launcher's Install screen suggests a folder and lets you Change it before you install. Veyra runs on 64-bit Windows only.

Your account

Is my website account the same as my launcher account?

Yes. An account you create here signs in to the launcher with the same email and password, and one made in the launcher logs in here.

What display names are allowed?

A display name is 3–16 letters, digits or underscores. Every name is unique, and capitals don't make a new one: if someone is Ember, nobody else can be ember.

I forgot my password

On the log in page, or the launcher's sign-in, select Forgot password? and enter your email. If an account uses it, a reset link arrives by email. Check your spam folder if it doesn't show up within a few minutes.

The launcher asks me to choose my name

Creating an account takes two steps: your sign-in, then your Veyra account with its display name. If the second step didn't finish (for example, the servers were offline, or someone took the name a moment before you), you'll be asked for a name the next time you sign in. Pick one there, or on your account page.

Do I need to verify my email?

Not during the current tests: you can sign in as soon as you register. Email verification will be required later in development.

Playing

The launcher says Veyra's servers are offline

Public tests run on Veyra's test servers, which aren't online around the clock. While they're offline you can't sign in to the launcher, download, or play. The status on this page shows whether they're up; try again when it reads Servers online.

The game won't start, or something went wrong
  1. Select Try Again in the launcher.
  2. Use Repair, beside the build number on the sign-in screen. It checks every file and replaces any that are damaged.
  3. Still stuck? Uninstall Veyra (keep the game when asked), run the latest Veyra Setup, and try once more.
How do updates work?

Automatically. Each time the launcher opens, it checks for a new launcher and a new game build and installs them before you sign in, downloading only what changed.

How do I uninstall Veyra?

Open Windows Settings → Apps → Installed apps, find Veyra and select Uninstall. You'll be asked whether to remove the game as well.
