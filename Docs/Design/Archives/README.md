# Design Archives

This directory preserves superseded versions of Veyra design bibles.

These files are **historical references only**. They are useful for tracing how a design evolved, comparing earlier decisions, or recovering intentionally removed ideas. They are not current canon and should not be used as implementation requirements unless a newer document explicitly restores a rule.

Current design bibles live one level up in `Docs/Design/`.

## Archive organization

- `Battleground/` — superseded Battleground Bible versions
- `Combat/` — superseded Combat Bible versions
- `MatchFlow/` — superseded Match Flow Bible versions (once a successor exists)
- `InitialRoster/` — superseded Initial Roster Character Bible versions
- `World/` — superseded World Bible versions

When a new bible version becomes current, keep the newest version in `Docs/Design/` and move the replaced version into the appropriate archive folder.
