# Veyra Character Concept Art

This directory is the repository home for current Vanguard character-sheet concept art.

These sheets are **visual development references**, not final production assets. The character designs, ability layouts, costume details, wording, and presentation may evolve during production. Canonical text design lives in [`Docs/Design/`](../../Docs/Design/).

## Current sheet set

## Public-repository note

Some early visual-development sheets may contain third-party inspiration/placeholder references used during ideation. Those references are not intended as Veyra production assets, branding, or claims of ownership. Public-facing final concept sheets should eventually be cleaned to contain only Veyra-owned visual material.
